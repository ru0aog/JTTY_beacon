# 🛰️ JTTY-радиомаяк на RP2040


**JTTY_beacon** — это реализация автономного JTTY-передатчика на примере использования библиотек jtty_codec (кодек формата JTTY) и mfsk_tonegen (программный генератор радиочастоты) на плате RP2040.
Проект ориентирован на радиолюбительские эксперименты, исследование прохождения радиоволн и оперативную передачу телеметрии в эфир.

> **Текущая версия:** `1.00` от `2026-10-16`

---

## ⚡ Основные возможности

* **Аварийная кнопка:** Передача заранее составленной фразы на заранее определённой частоте по нажатию кнопки USR.

---

## 🎛️ Аппаратная часть

Маяк спроектирован под аппаратную архитектуру чипа RP2040.

### Выход ВЧ-сигнала (VFO)
* **`PIN_RF_OUT = 15`** — переменная определяет выходной пин для подключения к буферному усилителю или антенной цепи при работе встроенного PIO/DDS генератора.
* **`JTTY_FREQ_HZ = 10001500UL`** — переменная определяет центральную частоту выходного сигнала в Гц.
* *Аппаратное ограничение программного DDS:* Обеспечивает чистую и стабильную сетку частот на КВ-диапазонах до **14–15 МГц**. На диапазоне 10 метров (28 МГц) генерация возможна, но уровень спуров повышен.

## 📦 Как скачать и установить готовую прошивку

Вам не обязательно устанавливать среды разработки для запуска маяка. Вы можете использовать полностью готовые бинарные файлы прошивки:

### 1. Официальные релизы (Рекомендуется)
Перейдите на страницу **[GitHub Releases](https://github.com/ru0aog/JTTY_beacon/releases)**. При создании каждого нового тега версии (`v*`) робот автоматически компилирует код и прикрепляет чистый файл **`.uf2`** в раздел *Assets*.

### 2. Свежие сборки «на лету»
Если вы хотите протестировать самые последние изменения, перейдите на вкладку **[GitHub Actions](https://github.com/ru0aog/JTTY_beacon/actions)**, выберите самый верхний успешный запуск сборки и скачайте архив артефакта **`arduino-rp2040-uf2`** из нижней части страницы.

### Инструкция по прошивке:
1. Зажмите аппаратную кнопку **BOOTSEL** на вашей плате (RP2040 / RP2040-Zero).
2. Не отпуская кнопку, подключите плату по USB-кабелю к компьютеру, после чего отпустите её.
3. В системе появится новый съемный накопитель **`RPI-RP2`**.
4. Просто **скопируйте (перетащите)** ваш скачанный `.uf2` файл на этот диск. Плата автоматически перезагрузится, применит прошивку и сразу начнет работу по заданному алгоритму.

## 💻 Сборка из исходного кода

Для самостоятельного изменения логики и локальной компиляции проекта вам понадобятся:

1. Среда разработки **Arduino IDE**.
2. Установленное стороннее ядро плат **Raspberry Pi Pico/RP2040** от *Earle F. Philhower* ([индекс плат](https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json)).

### Конфигурация платы в Arduino IDE (FQBN):
При прошивке из IDE или сборке через CLI используйте следующие настройки:
* **Плата:** *Raspberry Pi Pico* (или аналогичная RP2040)
* **USB Stack:** *Pico SDK*
* **Flash Size:** *2MB (Sketch: 1MB, FS: 1MB)* 
* *Строка FQBN для компилятора:* `rp2040:rp2040:rpipico:usbstack=picosdk,flash=2097152_1048576`

---

### Режим JTTY  
  
* Порт протокола JTTY из WSJT-X 3.3: 4-FSK, символ 32 мс, кадр 59 символов (13 синхротонов + 46 кодированных), свёртка K=10 с полиномами `0o1167/0o1545`, CRC-12 `0x80F`, Gray-кодирование дибитов. Полоса 4 тона с шагом 31.25 Гц, длительность кадра 1.888 с. Частота задаётся параметром `FREQ_JTTY` (центр полосы; нижний тон = `FREQ_JTTY − 46.875 Гц`).
